# Pwn Skill

## 目标

在受控题目副本中识别内存破坏原语并构造可复现的本地验证。

## 建议顺序

1. `file`、`checksec`、符号/字符串和输入交互基线。
2. 用最小输入确定崩溃位置、长度、覆盖范围和保护机制。
3. 判断 ret2win、ret2libc、ROP、格式化字符串、堆或其它路线；每一步保留调试日志。
4. 先对本地副本验证 `pwntools` 脚本，再连接明确授权的服务。
5. 给 payload、依赖、libc、架构和超时写出复现说明。

动态调试需要专用 runtime；没有策略授权时停止，不通过提权或 privileged 容器绕过限制。
