# Crypto Skill

## 目标

从题目给出的样本和约束推导可验证的数学解，优先使用短脚本复现。

## 建议顺序

1. 统一 hex/base64/整数/字节表示，记录端序和长度。
2. 检查重复 nonce、低熵随机数、已知明文、密钥复用、模数关系和 padding。
3. 先推导公式，再用 `gmpy2`/`SymPy`/`Z3` 实现；控制搜索空间和运行时间。
4. 对候选结果做解密、重加密、签名验证或 Flag 格式验证。
5. 保存 `scripts/solve.py`、固定输入和验证输出。

## 输出

报告必须说明假设、公式、参数、脚本运行方式和为何排除其它候选，不能只给出一个数字或字符串。
