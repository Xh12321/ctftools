# Reverse Skill

## 目标

从静态结构和受控动态行为中定位关键校验逻辑，并提供最小复现。

## 建议顺序

1. 保留原始样本哈希，确认格式、架构、入口和依赖。
2. 使用 `strings`、`objdump`/`readelf`、反编译器或 APK 工具定位输入、比较和解密路径。
3. 必要时在专用沙箱使用 `gdb`、`strace`、`ltrace` 或 `angr`，设置超时和输出上限。
4. 将关键常量、地址、控制流和输入构造成脚本验证。
5. 把补丁/patch 仅作为分析辅助，不覆盖原件。

静态分析优先；动态样本不能访问宿主机、其它任务或 Docker Socket。
