# Web Skill

## 目标

在题目授权范围内建立可复现的 Web 攻击面画像，并用最小请求验证假设。

## 建议顺序

1. 记录 URL、端口、题目范围和请求停止条件。
2. `curl -i` 保存首页、robots、重定向和关键 API 响应。
3. 用 `file`/`whatweb`/Header/Cookie 判断框架、服务器和认证方式。
4. 对有限字典做目录/文件枚举；每个发现都写入 `evidence/`。
5. 针对已确认的输入点检查注入、访问控制、文件处理、SSRF、模板和 JWT；默认只读验证。
6. 用独立脚本重放最小 PoC，校验题目 Flag 格式。

## 输出

保留原始响应、请求参数、时间戳和验证脚本。任何会改变远端状态的动作必须获得人工确认。
